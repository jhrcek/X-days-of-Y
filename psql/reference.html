Everything, on one page

Every key, command and option introduced by the course, with the day it first appears. This is the page to keep open while the habits settle.

Keys

KeyDoesDay
C-cAbandon the line you are typing and empty the query buffer.1
C-dEnd the session — but only when the buffer is empty.1

UpC-pThe previous line from the history.7

Commands

CommandDoesDay
psqlConnect with the defaults and start an interactive session.1
;Dispatch the buffer. Not a meta-command — SQL's own statement terminator.1
\gDispatch the buffer, exactly as a semicolon does.1
\pPrint the buffer without sending it. \print in full.1
\rReset: throw the buffer away. \reset in full.1
\eEdit the buffer in $EDITOR; on exit it is re-parsed and run.1
\w fileWrite the buffer to a file instead of sending it.1
\;Append a semicolon to the buffer without dispatching it.1
\?Every meta-command, in twelve groups. 121 of them in 18.6.1
\h SELECTSyntax for one SQL command. \h alone lists what it knows.1
\qQuit.1
\c dbnameReconnect to another database, reusing host, port and user.2
\c - userReconnect as another user. A dash means “leave that one as it is”.2
\c -reuse-previous=on ...Merge a conninfo string onto the current parameters.2
\conninfoA twelve-row table describing the live connection.2
\passwordChange a password without it reaching your history or the server log.2
\encodingShow the client encoding, or set it.2
\dBare: tables, views, materialized views, sequences and foreign tables.3
\d my_tableDescribe one relation: columns, types, nullability, defaults, indexes, constraints.3
\d+ my_tableAdds storage, compression, stats target and per-column comments.3
\dtTables. The letters combine — \dti lists tables and indexes.3
\di \dv \dm \ds \dEIndexes, views, materialized views, sequences, foreign tables.3
\dnSchemas. \dn+ adds permissions and comments.3
\lDatabases, with owner, encoding, locale provider and privileges.3
\dPPartitioned tables and indexes; add n to include non-root ones.3
\dxInstalled extensions; \dx+ lists everything each one owns.3
\df patternFunctions, with result type, argument types and kind.4
\df pattern t1 t2Extra arguments are type patterns, matched positionally.4
\sf nameThe function's source as CREATE OR REPLACE. \sf+ numbers the body.4
\sv nameThe same for a view. \ev and \ef edit rather than show.4
\duRoles and their attributes. \dg is the same command.4
\drgRole grants: who is a member of what, with ADMIN/INHERIT/SET.4
\dpAccess privileges on tables, views and sequences. \z is the same command.4
\ddpDefault privileges — what future objects will be created with.4
\dconfigServer parameters set to non-default values. \dconfig * for all of them.4
\drdsSettings attached to a role, a database, or the pair.4
\dT \do \daTypes, operators and aggregates — same grammar, rarer questions.4
\psetWith no argument, print all 22 printing options and their current values.5
\xToggle expanded mode. \x auto is the setting worth keeping.5
\a \t \f \C \HShortcuts kept for compatibility: format, tuples_only, fieldsep, title, HTML.5
\setWith no argument, list every variable currently set, with its value.6
\set NAME valueSet a psql variable. Several values are concatenated.6
\unset NAMEDelete it — or, for a control variable, restore its default.6
\echo :NAMERead a variable back. The cheapest debugging tool psql has.6
\i ~/.psqlrcRe-read the startup file without restarting. Tilde expansion works.6
\eEdit the buffer — or a file, or the last query — optionally at a line number.7
\ef nameFetch a function's definition into your editor. \ev for a view.7
\s filePrint the command history, or write it to a file.7
\errverboseRepeat the last error at maximum verbosity, changing no settings.8
\timing onReport how long each statement took. Milliseconds, then m:ss past a second.8
\copy tbl FROM 'file'Client-side load. psql reads the file, as you, with no server privileges.9
\copy (query) TO 'file'Client-side export. A table name, or a query in parentheses.9
\copy tbl FROM PROGRAM 'cmd'Run a command on the client and load its output. TO PROGRAM pipes out.9
\copy tbl FROM stdinData rows follow, up to a line containing only \..9
\copy ... TO pstdoutpsql's real stdout, ignoring \o. pstdin is the input twin.9
\copy ... FROM 'f' WHERE condFilter rows as they load — the condition is evaluated server-side.9
COPY ... TO STDOUT then \g fThe multi-line, interpolating alternative to \copy.9
\o filePoint all future query output at a file. Bare \o restores stdout.10
\o |commandPipe all future query output to a shell command.10
\g fileThis one query's output to a file. \g |cmd pipes it instead.10
\g (opt=val ...)A one-shot \pset for this query only.10
\qecho textWrite to the query-output channel, so it lands in the same file.10
\warn textWrite to standard error, so it never lands in the file.10
\w fileWrite the query buffer — not its output — to a file.10
\lo_import fileStore a file as a large object. Also \lo_export, \lo_list, \lo_unlink.10
\i fileRead and execute a file. The path is relative to the current directory.11
\ir fileThe same, resolved relative to the directory of the including script.11
\! commandRun a shell command. With no argument, a sub-shell until you exit it.11
:nameSubstitute the value literally — unquoted, unchecked, unsafe.12
:'name'Substitute as a properly quoted SQL literal. Handles embedded quotes.12
:"name"Substitute as a properly quoted SQL identifier. Handles spaces and case.12
:{?name}TRUE or FALSE depending on whether the variable exists.12
`command`Substitute a shell command's output, trailing newline removed.12
\gset [prefix]Store a one-row result into variables named after its columns.12
\getenv var ENVVARRead an environment variable into a psql variable.12
\setenv NAME valueSet an environment variable for psql and anything it runs.12
\prompt [text] nameAsk the operator for a value and store it.12
\gexecRun the buffer, then execute every cell of the result as SQL.13
\gdescReport the result's column names and types without running it.13
\crosstabview colV colH colDPivot the result into a grid. Two columns become the axes.13
\watch i=N c=N m=NRe-run the buffer every N seconds, at most N times, while it returns N rows.13
\if expressionOpen a block. The expression is interpolated, then read as a Boolean.14
\elif expressionAnother arm. Not evaluated at all once an earlier arm has matched.14
\elseAt most one, and last before the \endif.14
\endifClose the block. Must be in the same source file as its \if.14
\bind [param ...]Bind parameters for the next execution, and switch it to the extended protocol.16
\bind_named name [param ...]The same, against a statement already prepared by \parse.16
\parse namePrepare the buffer under a name. An empty string means the unnamed statement.16
\close_prepared nameClose a prepared statement. A no-op if there is no such statement.16
\startpipeline \endpipelineOpen and close a pipeline. Everything inside uses the extended protocol.16
\sendpipelineAppend the current buffer to the pipeline. \g is refused inside one.16
\syncpipelineSend a sync without ending the pipeline. Also the error-recovery point.16
\flushrequest \flush \getresultsAsk the server for results, push unsent bytes, read results back.16
\? [topic]commands (default), options or variables. Three manuals, none of them the man page.17
\encoding [name]Show or set the client encoding. Sets ENCODING too.17
\restrict key \unrestrict keyBlock every meta-command but the matching \unrestrict. Used by pg_dump.17
