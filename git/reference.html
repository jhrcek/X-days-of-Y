▚21 Days of git

Reference

Everything, on one page

Every key, command and option introduced by the course, with the day it first appears. This is the page to keep open while the habits settle.

Commands

CommandDoesDay
git init -b mainCreate an empty repository whose first branch is main.1
git hash-object <file>Print the object name the file's contents would get. Writes nothing without -w.1
git cat-file -t <object>Print an object's type: blob, tree, commit or tag.1
git cat-file -p <object>Pretty-print an object's contents. The one command that shows what git really stores.1
git cat-file -s <object>Print an object's size in bytes.1
git ls-tree -r <tree-ish>List every blob in a tree, recursively, with mode and hash.1
git rev-parse HEADTurn a name into the full hash it currently means.1
git count-objects -vCount loose and packed objects and the disk they use.1
git status -sShow each changed path with two columns: index vs HEAD, then working tree vs index.2
git add <path>Copy the file's current contents into the index. Writes the blob immediately.2
git add -pWalk through each hunk and choose which ones go into the index.2
git diffShow what differs between the index and the working tree — what add would stage.2
git diff --stagedShow what differs between HEAD and the index — what commit would record.2
git restore <path>Overwrite the working-tree file with the index version. Discards unstaged edits.2
git restore --staged <path>Reset the index entry to HEAD's version. The working tree is untouched.2
git commit [-a]Turn the index into a tree, wrap it in a commit, move the branch to it. -a first stages every modified tracked file (never untracked ones).2
git rm --cached <path>Remove a path from the index only; the file stays on disk, now untracked.2
git branchList local branches; * marks the one HEAD names.3
git branch -vList branches with the commit each points at and its subject line.3
git branch <name>Create a branch at HEAD without switching to it.3
git switch <branch>Point HEAD at a branch and update the index and working tree to its commit.3
git switch -c <name>Create a branch at HEAD and switch to it in one step.3
git switch -Switch back to the branch you were on before.3
git switch --detach <commit>Point HEAD directly at a commit, with no branch in between.3
git branch -d <name>Delete a branch, refusing unless it is merged into its upstream (or into HEAD, if it has none).3
git branch -D <name>Delete a branch unconditionally.3
git branch -m <old> <new>Rename a branch.3
git merge <branch>Bring the branch's history into the current one: fast-forward if possible, else a merge commit.4
git merge --ff-only <branch>Merge only if it is a fast-forward; otherwise refuse and change nothing.4
git merge --no-ff <branch>Always create a merge commit, even when a fast-forward was possible.4
git merge --abortGive up a conflicted merge and restore the state before it started.4
git merge-base A BPrint the best common ancestor of two commits — the version a merge compares against.4
git ls-files -uList the unmerged index entries: one line per stage per conflicted path.4
git show :1:<path>Show the base version of a conflicted file. :2: is yours, :3: theirs.4
git checkout --conflict=merge <path>Recreate the conflict markers in a file you mangled; =zdiff3 works too.4
git clone <url>Copy a repository: all objects, its branches as origin/*, and one local branch checked out.5
git remote -vList remotes with their fetch and push URLs.5
git remote add <name> <url>Register another repository under a short name.5
git fetchDownload new objects and move the remote-tracking refs. Never touches your branches or files.5
git pullFetch, then integrate the upstream into the current branch.5
git pushSend the current branch's commits and move the branch of the same name on the remote.5
git push -u origin <branch>Push and record origin/<branch> as this branch's upstream.5
git push origin --delete <branch>Delete a branch on the remote.5
git branch -vvList branches with their upstream and ahead/behind counts.5
git log --oneline --graph --allDraw every branch's history, one line per commit.6
git log -pShow each commit's diff against its parent.6
git log --statShow which files each commit touched, and how much.6
git log --author=<re> --since=<date>Keep only commits whose author matches, from a date onwards.6
git log -- <path>Keep only commits that changed the path. The -- separates paths from revisions.6
git log --follow -- <file>Follow one file's history back through renames.6
git log -S<string>Pickaxe: keep commits that change how many times the string occurs.6
git log -G<regex>Keep commits whose diff adds or removes a line matching the regex.6
git log -L :<func>:<file>Show the history of one function (or -L 10,20:file for a line range).6
git show <commit>Show one commit: message and diff.6
git blame -w -C <file>Annotate each line with its last commit, ignoring whitespace and seeing moves between files.6
git rev-parse --verify <rev>Resolve an expression to one object name, or fail. The checker for everything today.7
git rev-parse --abbrev-ref <rev>Print the short ref name an expression means: @{u} becomes origin/main.7
git rev-parse --symbolic-full-name <rev>Print the full ref name, e.g. refs/remotes/origin/main.7
git log A..BList commits reachable from B but not from A: what B has that A lacks.7
git log --left-right A...BList commits on either side but not both, marked < or >.7
git diff A...BDiff from the merge base of A and B to B: what B changed since they split.7
git show <rev>:<path>Print a file as it was in any commit, without checking anything out.7
git show :<path>Print the version of a file currently staged in the index.7
git commit --amendReplace the last commit with a new one built from the current index. Opens the editor.8
git commit --amend --no-editAmend, keeping the message: for the file you forgot to add.8
git reset --soft <rev>Move the branch to rev. Index and working tree untouched.8
git reset <rev>Move the branch and reset the index to it (--mixed, the default). Working tree untouched.8
git reset --hard <rev>Move the branch, and overwrite index and working tree to match. Destroys uncommitted work.8
git reset -- <path>Copy path from HEAD into the index: unstage. The branch does not move.8
git restore --source=<rev> <path>Overwrite a working-tree file with its version from any commit.8
git revert <commit>Make a new commit that undoes commit. The safe undo for published history.8
git clean -nList the untracked files -f would delete. Add -d for directories, -x for ignored files.8
git clean -fdDelete untracked files and directories. Ignored files survive unless -x.8
git rebase <upstream>Replay the commits in <upstream>..HEAD on top of upstream. With no argument, uses @{u}.9
git rebase --onto <new> <old> [<branch>]Replay <old>..<branch> on top of new: transplant part of a branch.9
git rebase --continueAfter resolving and git adding a conflict, commit it and go on.9
git rebase --skipDrop the commit that stopped, and go on.9
git rebase --abortPut the branch back exactly where it was before the rebase started.9
git push --force-with-leaseOverwrite the remote branch only if it is still where your remote-tracking branch says.9
git push --force-if-includesWith the lease: also refuse if the remote tip was fetched but never integrated locally.9
git rebase -i <base>Open the todo list for <base>..HEAD in your editor, then run it.10
git rebase --edit-todoRe-open the remaining todo list while a rebase is stopped.10
git commit --fixup=<commit>Commit the staged change as fixup! <subject>, to be melted into commit later.10
git commit --fixup=amend:<commit>Like --fixup, but the squash also replaces the target's message.10
git rebase -i --autosquash <base>Move every fixup!/squash!/amend! commit under its target and mark it.10
git rebase -x '<cmd>' <base>Run cmd after every replayed commit; stop at the first failure.10
git range-diff <base> <old> <new>Pair up the commits of two versions of a branch and show how each changed.10
git reflogList where HEAD has pointed, newest first, as HEAD@{n} entries. Short for git reflog show HEAD.11
git reflog show <branch>List where one branch has pointed. Its entries are <branch>@{n}.11
git reflog --date=isoShow each entry's time instead of its index: main@{2026-09-25 09:00:00 +0200}.11
git log -gWalk a reflog with the full git log formatting options.11
git reset --hard ORIG_HEADUndo the last reset, merge or rebase: go back to where it started.11
git branch <name> <commit>Give a recovered commit a name again, so it is safe for good.11
git fsck --unreachableList objects nothing refers to — not even a reflog. Where dropped stashes are found.11
git config list --show-origin --show-scopeList every setting in effect, with the file and scope it came from.12
git config get <name>Print the value git will use. Exit status 1 if unset.12
git config set [--global] <name> <value>Write a setting, to the repository's .git/config unless told otherwise.12
git config unset [--global] <name>Remove a setting from one file. Exit status 5 if it was not there.12
git config edit --globalOpen ~/.gitconfig in your editor.12
git -c <name>=<value> <cmd>Override one setting for one command, above every file.12
git help <alias>Print what an alias expands to.12
git stash push -m <msg>Save staged and unstaged changes to tracked files as a stash entry, and clean the tree.13
git stash push -uInclude untracked files. -a also takes ignored ones.13
git stash push --stagedStash only what is in the index.13
git stash listList entries; stash@{0} is the newest.13
git stash show -p [stash@{n}]Show an entry as a patch. Add --include-untracked to see its untracked files.13
git stash apply [--index]Reapply an entry and keep it. --index restores what was staged as staged.13
git stash pop [--index]Apply, and drop the entry only if it applied cleanly.13
git stash drop [stash@{n}]Delete one entry.13
git stash branch <name>Create a branch at the commit the stash was made on, apply it there, drop it.13
git worktree add <path> [-b <new>] [<branch>]Check out a branch in a new directory that shares this repository.13
git worktree listList every working tree with its HEAD and branch.13
git worktree remove <path>Delete a clean worktree. git worktree prune forgets ones you deleted by hand.13
git check-ignore -v <path>Print the file, line and pattern that decides whether path is ignored.14
git check-ignore -v --no-index <path>The same for a path that is already tracked.14
git status --ignoredAlso list ignored files, marked !!.14
git ls-files -o -i --exclude-standardList every untracked file the ignore rules are hiding.14
git add -f <path>Add a file despite an ignore rule.14
git check-attr -a -- <path>Print every attribute set on a path.14
git ls-files --eolShow line endings in the index and working tree, and the attribute in force.14
git add --renormalize .Re-apply the current text/eol attributes to every tracked file in the index.14
git archive HEADWrite a tarball of a commit, leaving out export-ignore paths.14
git cherry-pick -x <commit>Apply one commit's change on top of HEAD as a new commit, noting the original in the message.15
git cherry-pick A..BPick every commit in the range, oldest first. A itself is excluded.15
git cherry-pick --continue | --skip | --abortResume after resolving, drop the current commit, or return to where you started.15
git log --cherry-mark --left-right A...BMark commits on each side with = when the other side has an equivalent patch.15
git tag -a v1.2 -m <msg> [<commit>]Create an annotated tag: a tag object with tagger, date and message.15
git tag v1.2 [<commit>]Create a lightweight tag: just a ref.15
git tag -l 'v1.*'List tags matching a glob.15
git push origin <tag>Publish one tag. Tags are not pushed with branches by default.15
git push origin --delete <tag>Delete a tag on the remote.15
git describe [--tags] [--dirty] [--always]Name HEAD relative to the nearest annotated tag, e.g. v1.1-1-gc6dcec7.15
git bisect start <bad> <good>...Begin a search between a known-bad and one or more known-good commits.16
git bisect good | badMark the checked-out commit, and move to the next midpoint.16
git bisect skipThis commit cannot be tested; pick a nearby one instead.16
git bisect run <cmd> [args]Test every step automatically: exit 0 good, 1–127 bad, 125 skip, anything else abort.16
git bisect resetEnd the session and return to the branch you started on.16
git bisect logPrint the session so far as a replayable script.16
git bisect replay <file>Re-run a saved log, e.g. after correcting one wrong answer.16
git bisect view --onelineList the commits still in the running.16
git bisect termsShow the words in use for the two states.16
git merge -X ours <branch>Merge normally, but settle each conflicting hunk in favour of this side. Clean hunks from the other side still land.17
git merge -s ours <branch>Record a merge that keeps this tree exactly. The other branch's changes are discarded.17
git checkout --ours <path>During a conflict, take stage 2 for that path. In a rebase, stage 2 is the upstream.17
git checkout --theirs <path>Take stage 3 for that path. In a rebase, stage 3 is your own commit being replayed.17
git checkout -m <path>Re-create the conflict markers in a file you have mangled or resolved wrongly.17
git log --mergeDuring a conflict, list only the commits on either side that touch the conflicted paths.17
git diff AUTO_MERGEShow only what you have edited since git wrote the conflicted files.17
git rerere statusList paths whose conflict rerere has recorded a preimage for.17
git rerere diffShow the resolution you are about to teach rerere.17
git rerere forget <path>Drop a recorded resolution that turned out to be wrong.17
ls .git/hooksSee the sample hooks git init installed. None of them runs: they end in .sample.18
chmod +x .git/hooks/pre-commitEnable a hook. A hook without the executable bit is ignored, with a hint.18
git commit --no-verifySkip the pre-commit and commit-msg hooks for this commit. prepare-commit-msg still runs.18
git push --no-verifySkip the pre-push hook for this push.18
git hook run <name>Run a hook by hand, exactly as git would find it. Fails if it does not exist.18
git hook run --ignore-missing <name>Run it if it exists; succeed quietly if not. For scripts.18
git rev-parse --show-toplevelPrint the root of the working tree. The first line of most scripts.19
git rev-parse --git-dirPrint where the repository is — .git, or somewhere else entirely.19
git rev-parse --is-inside-work-treePrint true, or fail with status 128 outside a repository.19
git for-each-ref --format=… refs/heads/Print one formatted line per ref: the scriptable git branch.19
git status --porcelain=v2 --branch -zMachine-readable status, NUL-terminated, with branch and ahead/behind headers.19
git log --format=…Print commits through a template of %H, %an, %ad, %s and friends.19
git ls-files -zList tracked paths raw, NUL-terminated, without C-quoting.19
git cat-file --batch-checkRead object names on stdin; print hash, type and size for each. One process for thousands of objects.19
git var GIT_EDITORPrint the editor git would actually launch, after all the fallbacks.19
git count-objects -vHCount loose and packed objects, with human-readable sizes.20
git gcPack loose objects, pack refs, expire reflogs, prune old unreachable objects.20
git gc --prune=nowAlso delete unreachable objects at once, ignoring the two-week grace period.20
git verify-pack -v <pack>.idxList every object in a pack: size, packed size, delta depth and base.20
git fsckCheck every object's hash and every link between objects.20
git maintenance run --task=<task>Run one maintenance task now: gc, commit-graph, prefetch, loose-objects, incremental-repack…20
git maintenance startRegister this repository and install an hourly background schedule.20
git init --bareCreate a repository with no working tree — the shape of every server-side repository.20
git clone --no-local <path>Clone a local path through the normal transport, so objects are checked, not hard-linked.21
git help -gList the concept guides: tutorial, everyday, glossary, workflows, faq…21
git help -aList every command git knows, including git-* executables on your PATH.21
git help <command>Open that command's manual page. Same as git <command> --help.21

Options

OptionDoesDay
user.name / user.emailSet the identity written into every commit's author and committer lines.2
init.defaultBranchName the first branch of every new repository.2
commit.verboseShow the staged diff below the message in the commit editor.2
branch.sortSet the default order of git branch; -committerdate puts recent work first.3
merge.conflictStyleChoose the marker style: merge (default), diff3 or zdiff3.4
pull.ffonly: let git pull fast-forward and refuse anything else.5
push.autoSetupRemoteMake a plain git push of a new branch create it upstream and track it.5
fetch.pruneDelete remote-tracking refs whose branch was deleted on the remote, on every fetch.5
diff.colorMoved / diff.colorMovedWSColour moved blocks differently from added and removed ones; allow-indentation-change still recognises a re-indented move.6
push.useForceIfIncludesMake every --force-with-lease behave as if --force-if-includes were given.9
rebase.autoSquashMake rebase -i autosquash by default. Interactive mode only.10
rebase.updateRefsAlso move any branch that points into the rebased range (--update-refs).10
gc.reflogExpireAge after which reflog entries are pruned. Default 90 days.11
gc.reflogExpireUnreachableSame, for entries no longer reachable from the ref's tip. Default 30 days.11
core.logAllRefUpdatesWhether reflogs are kept. True by default with a working tree, false in a bare repository.11
includeIf."gitdir:<dir>/".pathRead another config file only for repositories under dir.12
alias.<name>Define git <name>. A leading ! makes it a shell command.12
GIT_CONFIG_GLOBALRead this file instead of ~/.gitconfig; /dev/null for none.12
GIT_PREFIXSet for shell aliases: the directory you ran them from, relative to the top level.12
core.excludesFileYour personal ignore file. Defaults to ~/.config/git/ignore — usually leave it.14
diff.<driver>.textconvA program that turns a file into text for diffs, used by paths with diff=driver.14
tag.sortDefault ordering for git tag -l; version:refname sorts v1.10 after v1.9.15
push.followTagsAlso push annotated tags that point into the history being pushed.15
--first-parentOn bisect start: follow only first parents, so merged side branches count as one step.16
--term-old=<w> --term-new=<w>On bisect start: use your own words instead of good/bad.16
rerere.enabledRecord every conflict and its resolution, and replay them on the next identical conflict.17
rerere.autoUpdateStage a path once rerere has resolved it, instead of leaving it for you to git add.17
core.hooksPathLook for hooks in this directory instead of $GIT_DIR/hooks. Replaces it; does not add to it.18
GIT_INDEX_FILESet for a pre-commit hook: the index being committed. Unset it before running git in another repository.18
-C <path>Run as if started in <path>. Global option: goes before the subcommand.19
--no-pager / -PNever pipe through the pager, even on a terminal.19
:(exclude)… / :!…Pathspec magic: everything except the matching paths.19
gc.pruneExpireHow old an unreachable object must be before gc deletes it. Default 2.weeks.ago.20
gc.cruftPacksKeep unreachable objects in a cruft pack rather than loose. Default true.20
gc.autoLoose-object count above which git gc --auto packs. Default 6700.20
--git-dir / --work-treePoint git at a repository and a working tree explicitly; turns off discovery.20
GIT_TRACE=1Print alias expansion, built-in and external command execution to stderr.21
GIT_TRACE_SETUP=1Print which .git, worktree, cwd and prefix git settled on.21
GIT_TRACE2_PERF=1Print timed regions — where the milliseconds went.21
GIT_TRACE_CURL=1Dump HTTP traffic. Authorization headers and cookies are redacted unless GIT_TRACE_REDACT=0.21
GIT_TERMINAL_PROMPT=0Never prompt for credentials on the terminal; fail instead. For scripts and cron.21
safe.directoryDirectories you trust although someone else owns them. Honoured only in protected (global, system, command-line) config.21
transfer.fsckObjectsCheck every object received by fetch or push, and abort on malformed or suspicious ones.21
help.autoCorrectWhat to do with a mistyped command: show a suggestion (default), prompt, run it, or never.21
