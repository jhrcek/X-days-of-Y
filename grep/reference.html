Commands

CommandDoesDay
grep root /etc/passwdSearch one named file. No filename prefix on the output.1
grep root /etc/passwd /etc/groupSearch several. Output gains a file: prefix automatically.1
grep rootNo file operand: read standard input. From a terminal, this waits for you.1
grep -r rootNo file operand and -r: search the working directory instead.1
cmd | grep root -A file operand of - is standard input, mixable with real files.1
echo $?Read the status grep just returned. The habit this whole day is about.1
grep -e -v file.txtSearch for the literal string -v. -e protects a pattern that starts with a dash.2
grep -f patterns.txt data.txtTake patterns from a file, one per line. The workhorse for long lists.2
cut -f1 ids.csv | grep -f - data.txtPatterns from a pipe. -f - reads them from standard input.2
if grep -q PAT f; thenThe correct predicate form. No output, stops at the first match.9
grep -q PAT f || [ $? -eq 1 ]Succeed on “no match”, still fail on a genuine error.9
grep -rlZ PAT . | xargs -0 CMDNUL-separated file names, safe for every legal name.9
find . -name '*.c' -print0 | xargs -0 grep -Hn PATWhen the filter needs directories, not just base names.9
${PIPESTATUS[0]}bash: the status of the first command in the pipeline, not the last.9
ps aux | grep '[s]shd'The bracket trick: the pattern no longer matches its own command line.9

Options

OptionDoesDay
-V, --versionPrint the version and exit. Know which grep you are actually running.1
--helpPrint the option summary and exit. Shorter and better organised than the man page.1
--End of options. Everything after it is a pattern or a filename, never a flag.1
-i, --ignore-caseMatch regardless of case. What counts as “the same letter” depends on the locale.2
--no-ignore-caseCancel an earlier -i. The last of the two on the line wins.2
-v, --invert-matchSelect the lines that did not match. Applied once, after all patterns.2
-w, --word-regexpRequire the matched substring to be bounded by non-word characters or line ends.2
-x, --line-regexpRequire the match to be the entire line. Silently overrides -w.2
-e PAT, --regexp=PATAdd a pattern. Repeatable, and combinable with -f.2
-f FILE, --file=FILEAdd every line of FILE as a pattern. An empty file matches nothing at all.2
-yUndocumented synonym for -i. In neither the man page nor --help, but 3.12 accepts it.2
.Match any single character. Whether it matches an encoding error is unspecified.3
[abc]Match one character from the list.3
[^abc]Match one character not in the list. The ^ must come first.3
[a-d]A range. In the C locale, ASCII order; elsewhere the standard says it is unspecified.3
[[:digit:]]A named class. The outer brackets are yours, the inner ones are part of the name.3
^ and $Anchor to the start and end of a line. They match a position, not a character.3
\< and \>Anchor to the start and end of a word. A GNU extension.3
\b and \BAnchor at, and not at, a word edge. \b is either edge; \< is only the left.3
\w and \WShorthand for [_[:alnum:]] and [^_[:alnum:]]. Note the underscore.3
*Zero or more of the preceding item. The only repetition operator BRE spells the same way.4
? and +At most one, and at least one. In BRE you must write \? and \+.4
{n,m}Between n and m times. {,m} with no lower bound is a GNU extension.4
|Alternation, and the loosest-binding operator there is. BRE spells it \|.4
(...)Group, to override precedence. BRE spells it \(...\).4
\1 … \9Re-match the exact text the nth group captured. Slow, and worth avoiding.4
-E, --extended-regexpExtended syntax: the operators above are bare. What you usually want.4
-G, --basic-regexpBasic syntax: ? + { | ( ) need backslashes. The default.4
-F, --fixed-stringsNo regex at all. Every pattern is a literal string, and it is the fastest matcher.4
-c, --countPrint the number of selected lines per file, not the number of matches.5
-l, --files-with-matchesPrint each filename that had a match, and stop reading that file at the first one.5
-L, --files-without-matchPrint each filename that had none. Read the gotcha about its exit status.5
-o, --only-matchingPrint each matched substring on its own line. Non-overlapping, empty matches dropped.5
-q, --quiet, --silentPrint nothing; exit 0 on the first match. The right way to use grep as a test.5
-m NUM, --max-count=NUMStop after NUM selected lines. -m0 reads nothing at all.5
-s, --no-messagesSuppress error messages about unreadable files. Does not change the exit status.5
--color[=WHEN]WHEN is never, always or auto. Nothing else, and abbreviations are refused.5
GREP_COLORSColon-separated SGR capabilities. Defaults to ms=01;31:mc=01;31:sl=:cx=:fn=35:ln=32:bn=32:se=36.5
-A NUM, --after-context=NUMPrint NUM lines after each match.6
-B NUM, --before-context=NUMPrint NUM lines before each match.6
-C NUM, --context=NUMPrint NUM lines on both sides.6
-NUMBare number: identical to -C NUM. grep -2 pat is the one worth typing.6
--group-separator=SEPPrint SEP instead of -- between non-adjacent groups.6
--no-group-separatorPrint no separator at all. What you want before piping into another tool.6
-n, --line-numberPrefix each output line with its 1-based line number.6
-H, --with-filenameForce the filename prefix. Automatic with two or more files.6
-h, --no-filenameSuppress the filename prefix. Automatic with one file.6
-b, --byte-offsetPrefix the 0-based byte offset. With -o, the offset of the match itself.6
-T, --initial-tabLine the content up on a tab stop, and pad the numeric fields to a fixed width.6
--label=LABELCall standard input LABEL instead of (standard input).6
-r, --recursiveDescend into directories, following symbolic links only if named on the command line.7
-R, --dereference-recursiveDescend, following every symbolic link. Can loop forever on a cyclic tree.7
-d ACTION, --directories=ACTIONread (the default, which fails on Linux), skip, or recurse — the last being -r.7
-D ACTION, --devices=ACTIONread (default) or skip, for devices, FIFOs and sockets. skip stops grep blocking on a pipe.7
--include=GLOBSearch only files whose base name matches GLOB.7
--exclude=GLOBSkip files whose base name matches GLOB.7
--exclude-dir=GLOBSkip directories whose base name matches GLOB. Trailing slashes are ignored.7
--exclude-from=FILERead a list of --exclude globs from a file, one per line.7
--binary-files=TYPETYPE is binary (default), text or without-match.8
-a, --textTreat binary input as text. Equivalent to --binary-files=text.8
-ITreat binary input as non-matching. Equivalent to --binary-files=without-match.8
LC_ALLOverrides every locale category at once. The variable to set in a script.8
LC_CTYPEDecides the character encoding: what a character is, and what is whitespace.8
LC_COLLATEDecides collating order, which is what range expressions like [a-z] consult.8
LANGThe fallback when neither LC_ALL nor the specific LC_* variable is set.8
POSIXLY_CORRECTStops grep permuting options after file names. Changes parsing, not matching.8
-Z, --nullWrite a NUL after each file name instead of a newline. Pairs with xargs -0.9
-z, --null-dataTreat input and output lines as NUL-terminated. Not the same option as -Z.9
--line-bufferedFlush after every output line. Costs throughput; needed when feeding a live tail.9
-P, --perl-regexpUse the PCRE2 engine. Accepts exactly one pattern, and may not be compiled in.10
\d \s \wDigit, whitespace, word character. The POSIX spellings are [[:digit:]] and friends.10
(?=...) and (?!...)Lookahead: assert what follows without consuming it.10
(?<=...) and (?<!...)Lookbehind: assert what precedes. The length must be fixed.10
\KDrop everything matched so far from the reported match. A lookbehind without the length rule.10
*? +? ??Lazy quantifiers: match as little as possible. POSIX has no equivalent.10
-PzNUL-terminated input, so a pattern can match across newlines. The manual calls this experimental.10

Distilled from the grep(1) manual page, checked against GNU grep 3.12.
