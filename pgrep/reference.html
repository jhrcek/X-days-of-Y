Commands

CommandDoesDay
pgrep sshdList the PID of every process whose name matches the ERE sshd.1
pgrep -u root sshdTwo criteria, AND-ed: owned by root and named sshd.1
pgrep -u root,daemonOne criterion, OR-ed: owned by root or by daemon. No pattern at all.1
pgrep 'systemd|cron'One ERE, two alternatives. Two bare patterns would be an error.1
pgrep --versionPrint the procps-ng version this course is checked against.1
pgrep -f 'python3 .*worker'Match the full command line, so the interpreter's arguments count.2
pgrep -x systemdOnly processes named exactly systemd — not systemd-logind.2
pgrep -A -f myscript.shMatch command lines, but ignore every ancestor of this pgrep.2
cat /proc/PID/commThe 15-character name pgrep matches by default.2
tr '\0' ' ' < /proc/PID/cmdlineThe full command line pgrep matches under -f.2
ps -fp $(pgrep -d, -x sshd)The man page's own idiom: hand a comma list to ps.3
renice +4 $(pgrep chrome)Word-splitting turns newline-separated PIDs into separate arguments.3
pgrep -a -Q -f workerList command lines with argument boundaries preserved.3
pgrep -P $$Everything your current shell forked directly.4
pgrep -t pts/3 -aEverything running on one terminal — the other window.4
pgrep -g 0Processes in pgrep's own process group; -s 0 does the same for the session.4
pgrep -n -a firefoxThe most recently started match, with its command line.5
pgrep -O 3600 -u $USER -aEverything of yours that has been running for over an hour.5
pgrep -r D -aProcesses in uninterruptible sleep — the ones a dying disk produces.5
ls /proc/PID/taskEvery thread of a process, by TID.6
cat /proc/PID/task/TID/commOne thread's own name — often nothing like the process's.6
pgrep -w -f nginxAll threads of every matching process, since threads share the command line.6
pkill -e -f 'python3 worker'Signal every match and say which ones. SIGTERM by default.7
pkill -HUP syslogdThe man page's own example: make a daemon reread its configuration.7
pkill --signal 0 -e -x myappSend nothing. A pure permission probe — but -e still says "killed".7
pidwait -e -x myappBlock until every match has exited, including processes you did not start.7
cut -d: -f3 /proc/PID/cgroupThe cgroup v2 path --cgroup wants, exactly as it wants it.8
systemctl status PIDWhich unit a PID belongs to — the reverse lookup --cgroup does not offer.8
ls -l /proc/PID/nsThe namespace identities a process is confined by.8
systemctl kill --signal=HUP unitSignal a unit's whole cgroup. No pattern, no race, no PID.9
killall -s 0 namePSmisc's tool: exact name matching by default, no regex unless you ask.9
pkill -A -f "${PAT:?}"The two guards that belong on every scripted pkill.9

Options

OptionDoesDay
-c, --countPrint how many processes matched instead of their PIDs.1
--quietPrint nothing; the exit status is the whole answer. Long form only.1
-f, --fullMatch against the whole command line instead of the process name.2
-x, --exactRequire the pattern to match the whole string, not a part of it.2
-i, --ignore-caseMatch case-insensitively.2
-A, --ignore-ancestorsDrop every ancestor of this pgrep from the result. The fix for -f in scripts.2
-l, --list-namePrint the process name after the PID. Still the 15-character name, even under -f.3
-a, --list-fullPrint the full command line after the PID.3
-Q, --shell-quoteShell-quote each argument in -a output, so boundaries survive. Undocumented.3
-d, --delimiterJoin the PIDs with this string instead of a newline. A trailing newline is still added.3
-u, --euidMatch on the effective user — the authority the process is acting with.4
-U, --uidMatch on the real user — who started it.4
-G, --groupMatch on the real group. Name or number.4
-P, --parentMatch processes whose parent is one of these PIDs.4
-g, --pgroupMatch on process group. 0 means pgrep's own.4
-s, --sessionMatch on session ID. 0 means pgrep's own.4
-t, --terminalMatch on controlling terminal, named without /dev/.4
-p, --pidMatch only these PIDs — a filter, not a lookup. Undocumented.4
-n, --newestKeep only the most recently started match.5
-o, --oldestKeep only the least recently started match.5
-O, --olderKeep matches started more than this many seconds ago.5
-r, --runstatesKeep matches in one of these kernel run states. A comma list.5
-v, --inverseReturn everything the query did not select — the whole query, not just the pattern.5
-w, --lightweightWalk threads rather than processes: match every thread's own name, and print TIDs.6
-F, --pidfileRead PIDs from a file and use them as a criterion.6
-L, --logpidfileWith -F, fail unless the pidfile is locked.6
--signal SIG, -SIGWhich signal to send. Name or number. Default SIGTERM.7
-e, --echoPrint a line per process signalled. Says "killed" whatever the signal was.7
-q, --queue NUse sigqueue(3) and attach this integer to the signal.7
-H, --require-handlerOnly signal processes that have a userspace handler for that signal.7
-m, --mreleaseRelease the target's memory immediately after signalling. Undocumented.7
--cgroupMatch on cgroup v2 path. The whole path, leading slash included. A comma list.8
--ns PIDMatch processes sharing all of this PID's namespaces. Needs root to be correct.8
--nslistRestrict which namespaces --ns compares. Broken for lists of more than one.8
--env NAME=VALUEMatch on an environment variable, or just NAME for its presence. Undocumented.8
